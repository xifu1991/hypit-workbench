# 素材与风格对齐分析

## 素材事实

素材是同一机位、同一场景的竖屏口播：主播中景站位，手举香水逐支讲解，烧录字幕固定在画面 76%–84% 高度。
全片没有独立的产品空镜、氛围图或原料画面，产品只出现在主播持握的同一机位里。

## 风格要求与差距

参考风格的可复用部分是语义切画面、完整人物与产品画面交替、底部跟读字幕加独立卖点花字、开头结尾回到完整人物。
参考里“全屏产品/氛围画面”依赖独立 B-roll；本素材没有这类镜头，因此不能照着参考做出同强度的产品画面。

## 本次采用的做法

用同一真实素材做两级景别：完整人物镜头与语义对应的中近景推入镜头交替。
推入镜头把瓶身、手部与持握关系放到画面主体，人物脸部保持完整，从而在只有一个机位的前提下仍然形成“人物 → 产品”的节奏。
烧录字幕在推入镜头里被裁掉，因此在这些段落改用工程内的独立字幕轨补足阅读，避免两层字幕叠加。

## 已知限制

- 没有独立产品/氛围素材，产品画面强度低于参考；补齐方式是补拍瓶身空镜、原料或使用场景。
- 烧录字幕属于原片，无法拆成独立可编辑层，只能整段保留或整段裁掉。
- 抠像小人需要无字幕母版或分割能力，本次未使用。
