# Treatment

按 `armani-yulong-clean-talk@0001` 的语义切画面结构重排这条香水口播：

- 开场与三支香水总览用完整人物建立信任，并在结尾回到完整人物收束。
- 每支香水的钩子、香调拆解、场景描述切到中近景推入镜头，让瓶身与手部成为画面主体。
- 大号黄底花字只提炼产品名、香调关键词与结论，与口播同步按语义更换。
- 中近景段落由工程内的独立字幕轨承接跟读字幕，完整人物段落保留原片烧录字幕，避免重复文字。
- 画面节奏按语义而不是机械定时，单镜保持约 2–8 秒，长段落拆成两次不同取景。

推入镜头在 1.50 → 1.60 之间缓慢推进，取景中心随每个镜头的瓶身位置调整；不做过场式无意义缩放。
